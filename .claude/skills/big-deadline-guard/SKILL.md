# BIG 締切当日ガード — 手順書

目的: 締切当日に +EV(造船太郎)窓の最終確認を**締切に間に合うタイミングで**必ず1回入れること。台風などの試合中止は公式確定がキックオフ直前＝締切直前になりがちで、朝の定期モニタだけでは「中止1試合で+EV」に跳ねた瞬間を取りこぼす。

**設計の前提（2026-08-08 改修の理由）**: BIG/toto の販売締切は **Jリーグ対象回では初戦キックオフの10分前**＝土曜の昼〜夕方（第1644回は初戦KO14:45→締切14:35）。オフシーズンの海外リーグ回は火曜19:00等。**締切時刻が回ごとに動くので、固定時刻の最終チェックは構造的に成立しない**（旧設計の毎日16:00固定は第1644回の14:35締切を取りこぼす欠陥だった）。そこで「毎朝、今日が締切日かを判定し、締切75分前に単発タスクを自己装填する」方式を取る。

これは無人実行。承認プロンプトを出さない書き方で進め、判断は自律的に行う。**このガードに限り、単発の最終チェックタスクを scheduled-tasks ツールで作成・更新する write 行為を明示的に許可する**（それがこのタスクの目的そのもの）。

## 手順

1. 主ソース https://store.toto-dream.com/dcs/subos/screen/pi02/spin005/PGSPIN00501InitBIGLotInfo.form を取得し、発売中の回号と販売締切日時（ネット決済／コンビニ決済）を読む。
2. **販売締切（ネット決済）が本日でなければ**、「本日締切なし・スキップ（発売中: 第◯回 締切◯/◯ ◯:◯◯）」の1行だけ出力して終了。フル計算はしない。
3. **販売締切が本日なら**、締切までの残り時間で分岐:
   - **残り2時間以内** → 単発を装填している猶予はない。**いまここでフル最終チェックを実行**（下の「最終チェックの中身」）。
   - **残り2時間超** → `mcp__scheduled-tasks__create_scheduled_task` で単発タスクを装填する:
     - taskId: `big-carryover-deadline-oneshot`
     - fireAt: **ネット締切の75分前**（ISO 8601・+09:00）
     - description: 「第◯回 締切◯:◯◯ の75分前・+EV窓の最終チェック（自動装填）」
     - prompt: 「BIG/MEGA BIG 締切直前の最終チェック。手順・鉄則・カナリア・出力ルールはすべて C:\workspace\finance-stack\world-toto-lab\.claude\skills\big-carryover-monitor\SKILL.md に従い、フルの監視手順（lot-info取得→公式お知らせでM認定→calculatorで真EV→判定報告）を実行する。+EV窓が開いていれば締切時刻（ネット/コンビニ両方）を明記して最優先アラート。金額は推奨しない。」
     - 既に同 taskId が存在してエラーになる場合は `mcp__scheduled-tasks__update_scheduled_task` で fireAt を差し替えて再装填する（update は自動で re-arm される）。
     - 装填したら「単発チェックを◯:◯◯に装填（締切◯:◯◯）」と報告して終了。
4. コンビニ決済締切はネットより早い（1644実測: ネット14:35/コンビニ12:45）。アラート文には両方を明記する。

## 最終チェックの中身（残り2時間以内 or 単発タスク側で実行）

手順・鉄則・カナリア・出力ルールは**すべて**姉妹スキルに従う（重複記載しない・あちらが正）:
[.claude/skills/big-carryover-monitor/SKILL.md](../big-carryover-monitor/SKILL.md)

要点のみ再掲:

- バナーの「約◯億円」は使わずテーブルの商品別繰越を採用。繰越 `-` は未確定でありゼロではない。
- 中止数 M は toto 公式お知らせのみ。延期・振替は除外。中止カードは指定試合リストと突き合わせ。
- EVは手計算せず、スクラッチパッドに Write したスクリプトを `npx tsx` で実行（calculator を絶対パス import）。
- **+EV窓が開いている**（公式確定の現Mで真EV≥1 かつ 想定最終売上 < 実効売上天井 かつ 中止確定が締切前＝ゲートA）→ **締切に間に合うよう最優先でアラート**。金額は推奨しない。
- カナリア該当時は「取得失敗」と明示報告し、EV判定を出さない。
