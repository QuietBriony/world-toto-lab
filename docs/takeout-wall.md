# 控除率の壁 — 予測モデルはどこで現金化できるか

作成日: 2026-08-08

BIG レーンと W杯 toto レーンで別々に扱っていた式が同一だと分かったので、1か所にまとめる。

実装: [`src/lib/parimutuel-edge.ts`](../src/lib/parimutuel-edge.ts)（判定は必ず関数で出す。この文書に式を写して手計算しない）

---

## 1. パリミュチュエルの EV は2因子に分解できる

売上 S・払戻率 r・キャリー C の場で、ある出目に1口賭ける。群衆がその出目に張っている
割合を p_public とすると、的中時の当せん口数 ≈ S × p_public。よって

```text
EV = (p_model / p_public) × (r + C/S)
       ~~~~~~~~~~~~~~~~~     ~~~~~~~~~
       優位比                原資倍率
```

- **優位比** = 群衆に対してどれだけ正しいか。予想スキルで動かせる唯一の因子。
- **原資倍率** = 場の構造。**予想スキルでは1ミリも動かせない。**

→ `parimutuelEvBreakdown()` は合成後の EV だけでなく、この2因子を分けて返す。
どちらが効いている／足りないのかを取り違えないため。

## 2. 必要な優位比は控除率だけで決まる

EV ≥ 1 の条件は `p_model / p_public ≥ 1 / (r + C/S)`。キャリーが無い平常回では：

| 場 | 払戻率 r | 必要な優位比 |
| --- | --- | --- |
| **スポーツくじ（toto / BIG / WINNER）** | **0.50** | **2.00 倍** |
| 公営競技（競馬・競輪等の目安） | 0.75 | 1.33 倍 |
| 手数料が数%の場 | 0.98 | 1.02 倍 |

スポーツくじの 0.50 は約款で「売上金額の50%を払戻対象基礎額」と規定された固定値
（出典: [toto公式](https://www.toto-dream.com/toto/about/) ／
[総務省 実効還元率資料](https://www.soumu.go.jp/main_content/000084191.pdf)）。

**つまり toto で勝つには、群衆の2倍正しい必要がある。**「よく当たる」では全く足りない。

## 3. 「公衆過信の発見」は +EV の理由にならない

第1637回 M01（Ecuador vs Germany）で、公衆はドイツ 73.8%・Polymarket は 64.3% だった。
公衆が過信しているのは事実だが、この出目の優位比は 0.643 / 0.738 = **0.87** にしかならない。
裏側（公衆 26.2% に対し市場 35.7%）を取っても優位比 1.36 → EV 0.68 で、やはり 2.0 に届かない。

→ **市場シグナルの正しい用途は「割引」であって「買い理由」ではない。**
公衆過信の本命を自動で割り引く（= `world-cup-market-signal.ts` が engine に入れている
Edge = 市場 − 公衆）のは正しい設計。そこから先、それだけで +EV を主張してはいけない。
この2ケースは `parimutuel-edge.test.ts` に回帰テストとして固定してある。

## 4. BIG レーンとの一致

p_model = p_public（群衆と同じ予想しかできない）を代入すると EV = r + C/S。
これは `bigTrueEvUpperBound()` が返す BIG の殺到極限EVと**同一の式**で、
テストで数値一致を確認している（第1476回の実現アグリゲート 1.737 も再現）。

両レーンは別の戦略ではなく、同じ不変式の別断面：

| | 動かす因子 | 手段 |
| --- | --- | --- |
| BIG レーン | **原資倍率**（C/S を上げる） | 買い目は選べないので、キャリーが厚く売上が薄い回＝中止で確率が跳ねた回を待つ |
| W杯 toto レーン | **優位比**（p_model/p_public を上げる） | 買い目を選べるので、群衆が外している出目を当てにいく |

BIG 側で「エッジの源泉はキャリーではなく中止」なのは、C/S の S 側（殺到）が効くため。
[big-carryover-playbook.md](./big-carryover-playbook.md) §1 と同じ話をしている。

## 5. 帰結：モデルの価値は出口の控除率で決まる

同じ精度のモデルでも、r=0.50 の場に出せば 2.00 倍の壁、r=0.98 の場なら 1.02 倍の壁。
**モデルを良くする努力と、出口を選ぶ判断は、別々に効く。**後者のほうが桁で効く。

ただし本リポジトリにおいて Polymarket は**賭け先ではなく読み取り専用のシグナル源**である
（[MARKET_SOURCES.md](./MARKET_SOURCES.md) ／ market-sources は localStorage 専用・read-only）。
ここでの結論は「乗り換えろ」ではなく、**toto 側で +EV を主張するときは優位比 2.0 を
満たしているかを必ず `parimutuelEvBreakdown()` で確認する**という運用規律。
