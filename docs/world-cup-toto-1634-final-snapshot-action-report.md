## EVロジック確認

現行の1等EVロジックは次でよい。

```text
pModelCombo = 選択した13試合のモデル確率の積
pPublicCombo = 選択した13試合の公式人気率の積
expectedOtherWinners = (totalSalesYen / stakeYen - 1) * pPublicCombo
firstPrizePool = totalSalesYen * returnRate * firstPrizeShare + carryoverYen
estimatedPayoutIfHit = firstPrizePool / (1 + expectedOtherWinners)
grossEvYen = pModelCombo * estimatedPayoutIfHit
evMultiple = grossEvYen / stakeYen
```

重要なのは、確定売上が初期比20.72倍になっている点。売上が増えると1等原資は増えるが、人気寄りの組み合わせでは想定他当せん者も増える。逆に人気薄を含む組み合わせでは、原資増の効果が残りやすい。したがって「王道で当てた場合」と「期待値狙いの人気薄込み」は、確定人気・確定売上で再計算する必要がある。

### P0: スナップショットを履歴として保存

今の `Match.officialVote1/0/2` だけを上書きすると、6/7時点と6/12時点を比較できない。履歴として保存する入れ物が必要。

- id

まずは local repository 側だけでもよい。D1共有に広げる場合は、schema追加とWorker API追加を別PRに分ける。
