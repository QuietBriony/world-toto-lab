# toto 予測ログ（優位比レーン・事前登録 → 結果照合）

BIG の [big-carryover-prediction-log.md](./big-carryover-prediction-log.md) の toto 版。
toto は出目を選べるので、検定対象は「モデルの優位比 p_model / p_public」になる。
控除率の壁（[takeout-wall.md](./takeout-wall.md)）: r=0.50・キャリー無しでは
**優位比 2.0 以上の出目だけが +EV**。判定は `parimutuelEvBreakdown()` で出す。

**登録する予測（p_model 不在のため「モデル予想」ではなく構造ベースの仮説）**

1. **群衆本命線**（ベースライン・worldtoto の public favorite に相当）:
   `2-1-1-2-1-1-2-2-1-2-2-1-1`
   worldtoto の実績では public favorite は 1634 で9外し・1635 で2外し。今回の外し数を計測する。
2. **引き分け過小仮説**: Jリーグの引き分け基準率はおよそ25〜27%。群衆の 0 への投票が
   基準率を大きく割る試合（M5 11.26% / M2 17.95% / M4 16.20% / M6 17.71%）が、
   優位比 2.0 候補が「もし存在するなら」出る場所。ただし強い本命がいる試合の真の引分率は
   基準率より低い（15〜20%）ため、**オッズ無しでは優位比を確定できない**。
   → 明日の結果で「引分過小の4試合のうち実際に引分になった数」を記録する。
3. **EV の前提**: toto 1644 のキャリーオーバーは 0円（1637 の繰越 0円を確認済み）。
   よって原資倍率 = 0.50 で、**どの出目も優位比 2.0 未満なら EV < 1**。
   本登録は「買い推奨」ではない。

3等 4,090円×1,882口 ／ **繰越 0円**（1等が出たので1645にキャリーは乗らない）

**採点**:

1. **群衆本命線: 13試合中 5外し**（M3名古屋・M7東京V・M8長崎・M10藤枝・M11八戸）。
   worldtoto の先例（1634: 9外し／1635: 2外し）に 5外し が加わった。
2. **引分過小仮説（B）: 0/4**。ダブルにした4試合はすべて本命勝ち。今回の引分は M7 の1試合のみ
   （13試合で引分率 7.7% vs 基準率 25〜27%）＝ **ρ の初サンプルは 1 を大きく割る逆風**。1回の
   ノイズとして記録し、バックテストで分布を取るまで仮説は棄却も採択もしない。
3. **実購入20口の成績: 最良で4外し**（マルチ② M8=1 系の2口）・賞金圏(2外し)に届かず。
   収支 **−2,000円**。手組v2でも最良4外し（M8→1 の口）で同着＝構成選択は結果に影響せず。
